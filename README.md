# Портфолио Натальи Фроловой

Сайт на [Astro](https://astro.build): статичный, быстрый, без лишних скриптов. Дизайн-решения записаны в `DESIGN.md`.

## Где что менять

| Что | Где |
|---|---|
| Тексты главной, контакты, карточки кейсов | `src/data/site.ts` |
| Страница кейса Spok | `src/pages/cases/spok.astro` (текст прямо в разметке) |
| Фото для аватара | `public/avatar.jpg` + поле `avatar` в `site.ts` |
| Резюме | положить файл `public/cv.pdf` |
| Экраны кейсов | положить в `public/shots/<кейс>/` и указать путь: `image: '/shots/spok/home.webp'` |
| Логотипы компаний | положить в `public/logos/` и указать `logo: '/logos/nzvc.png'` |
| Картинка превью ссылки | `public/og.png` (1200×630) |
| Цвета, шрифты, отступы | `src/styles/global.css` (токены в начале файла) |

Жёлтые блоки «Черновик» на странице кейса — пометки для тебя. Заполни и удали их перед публикацией.

Пока у кейса нет `image`, на сайте показывается серая заглушка «Экран появится после ревью». **Перед отправкой ссылки рекрутерам заглушек быть не должно.**

Экраны: PNG или WebP. Сейчас экраны Migraine и Plutus собраны из рендера Figma в 1x — для ретины лучше переэкспортировать в 2x. На главной — шириной 2080px, внутри кейса — 2560px (широкие картинки до 1280px × 2 для ретины). До ~500 КБ каждый. Экраны кейса подключаются так: `<Shot wide tint={tint} src="/shots/spok/home.webp" alt="..." />` (для группы телефонов на прозрачном фоне добавь `phones`)`.

## Как опубликовать на Vercel (один раз)

1. Зарегистрируйся на [github.com](https://github.com), создай новый репозиторий (например, `portfolio`) и загрузи туда содержимое этой папки: **Add file → Upload files**, перетащить всё, **кроме** `node_modules` и `dist`.
2. Зайди на [vercel.com](https://vercel.com) → **Sign up with GitHub**.
3. **Add New → Project** → выбери репозиторий `portfolio` → **Import**. Vercel сам поймёт, что это Astro. Нажми **Deploy**.
4. Через минуту сайт будет по адресу вида `portfolio-xxx.vercel.app`. В настройках проекта (**Settings → Domains**) можно поменять имя или подключить свой домен.
5. Впиши итоговый адрес в `src/data/site.ts` (поле `url`) и в `astro.config.mjs` (поле `site`), иначе превью ссылки будет вести не туда.

## Как обновлять

Открываешь файл на GitHub → значок карандаша → правишь → **Commit changes**. Vercel пересоберёт сайт сам примерно за минуту.

## Запуск на своём компьютере (необязательно)

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # сборка в dist/
```
